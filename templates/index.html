RAG-system API

Välkommen till RAG-systemet

Detta är ett Retrieval-Augmented Generation (RAG) system som använder vektorembeddings för att hitta relevant information och generera svar.

Tillgängliga API-endpoints

Sök i RAG-databasen

GET /api/rag/search?q=din+sökfråga&limit=5

Söker efter relevant innehåll baserat på semantisk likhet.

Hybrid-sökning

GET /api/rag/hybrid-search?q=din+sökfråga&limit=5

Kombinerar vektorsökning med nyckelordsmatchning för bättre resultat.

Ställ en fråga

POST /api/rag/ask

Skicka en fråga och få ett svar baserat på relevant innehåll.

{
  "question": "Din fråga här"
}

Lägg till innehåll

POST /api/rag/add

Lägg till nytt innehåll i RAG-databasen.

{
  "content": "Innehåll att lägga till",
  "source_type": "custom",
  "source_id": "custom_1",
  "metadata": {
    "key": "value"
  }
}
